# IPL Dashboard Project

Source workbook: **IPL Dashboard Project.xlsx**

The workbook contains these sheets:
- **Sheet1** — 77 rows × 6 columns
- **Sheet2** — 20 rows × 10 columns
- **Dashboard** — dashboard sheet
- **IPL_Matches_2008_2022** — 950 match records × 18 columns

The IPL match data covers seasons from **2007/08 through 2022** and includes teams, venues, toss decisions, winners, win margins, player of the match, and umpires.

This repository commit adds the project documentation. The original Excel workbook remains the source file for the dashboard.
