## Source Workbook

`IPL Dashboard Project.xlsx` is the primary project artifact. The main analytical table is `IPL_Matches_2008_2022` with **950 match records and 18 fields**.

## Documentation Package

A complete downloadable package was generated containing the original Excel workbook, complete PDF report, Markdown documentation, data dictionary, analysis-ready CSV, metadata Excel workbook, and workflow/structure/data-flow diagrams.

The binary Excel/PDF/PNG artifacts require a binary-file upload route; the GitHub connector used here supports repository text-file writes but not arbitrary binary file uploads.
