# IPL Dashboard — Complete Workflow & Structure

## 1. Project Overview
This project is an IPL analytics/dashboard workbook built around historical Indian Premier League match data. The primary source workbook is **IPL Dashboard Project.xlsx**.

## 2. Workbook Structure
- **Sheet1** — 77 rows × 6 columns
- **Sheet2** — 20 rows × 10 columns
- **Dashboard** — dashboard sheet
- **IPL_Matches_2008_2022** — 951 rows including the header × 18 columns

The main match-data sheet contains **950 match records plus the header row**.

## 3. End-to-End Workflow
1. Collect historical IPL match records.
2. Store records in the Excel workbook.
3. Review field names, data types, missing values and consistency.
4. Prepare the dataset for dashboard analysis.
5. Build measures/KPIs around seasons, teams, tosses, wins, venues, players and match outcomes.
6. Build dashboard visuals and filters.
7. Validate totals and trends against the source data.
8. Document the model, workflow and interpretation.
9. Package the project for portfolio/review use.

## 4. Main Analytical Areas
- Season-wise match analysis
- Team participation and wins
- Toss winner and toss decision patterns
- Venue/city analysis
- Player of the Match frequency
- Win result/margin analysis
- Super Over occurrences
- Match-level exploration

## 5. Portfolio Presentation
**Problem → Dataset → Cleaning → Data Model → KPIs → Visuals → Insights → Conclusion**

## 6. Source Fields
The primary dataset has 18 fields covering match ID, city, date, season, teams, venue, toss, result, player of the match and umpires.

## 7. Important Note
The Excel workbook remains the authoritative source artifact. This documentation describes the project structure and recommended analytical workflow without inventing dashboard values.
